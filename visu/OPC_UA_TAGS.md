# Добавление OPC UA-тега

Подробный пример всей цепочки `CODESYS → gateway → client → React` находится в разделе 7–9 файла [VISUALIZATION_GUIDE.md](./VISUALIZATION_GUIDE.md).

Связь разделена на четыре уровня. Новый сигнал необходимо провести через все уровни, не обращаясь к OPC UA напрямую из React-компонента.

## Статус из PLC в HMI

1. Добавить переменную и атрибут публикации в `GVL_HMI` проекта CODESYS.
2. При необходимости заполнить переменную в `PLC_PRG` или соответствующем функциональном блоке.
3. Добавить NodeId и чтение в `gateway/server.mjs`.
4. Добавить поле в `src/model/types.ts` и начальное значение в `src/model/defaults.ts`.
5. Преобразовать значение в `mapPlcSnapshot` или `mapRuntimeInfo` файла `src/plc/client.ts`.
6. Показать поле в компоненте и добавить сценарий Storybook.

## Команда из HMI в PLC

1. Добавить командный бит или значение в `GVL_HMI` и опубликовать его через OPC UA.
2. Подключить команду к функциональному блоку в `PLC_PRG`.
3. Зарегистрировать человекочитаемое имя команды в `gateway/server.mjs`.
4. Из React вызвать только `plcClient.send({ command: 'area.action', ... })`.
5. Для импульсной команды шлюз должен записать `TRUE`, выдержать короткий импульс и вернуть `FALSE`.
6. Интерфейс подтверждает результат по статусу PLC, а не по факту нажатия кнопки.

## Проверка

```powershell
npm run build
node --check gateway/server.mjs
```

После импорта XML в CODESYS проверить страницу `/api/health`: обязательные символы не должны находиться в массиве `missing`.
