# Portal Robot HMI

Исходники интерфейса находятся в `src`, OPC UA gateway — в `gateway`, а инструкции для разработки — в [единой документации DOKS](../DOKS/README.md) в корне проекта.

## Запуск с PLC

PLC должен публиковать `GVL_HMI` через OPC UA. Текущий локальный endpoint:

```text
opc.tcp://127.0.0.1:4840
```

Разработка с автоматическим запуском шлюза и Vite:

```powershell
npm run dev:live
```

Промышленный запуск собранного интерфейса:

```powershell
npm run build
npm start
```

После этого HMI доступен по адресу `http://127.0.0.1:3001`.

## Настройка адресов

Адрес PLC и порты можно переопределить переменными окружения:

```powershell
$env:OPCUA_ENDPOINT='opc.tcp://192.168.0.181:4840'
$env:GATEWAY_PORT='3001'
npm start
```

В режиме разработки `npm run dev:live` сам публикует Vite на сетевом интерфейсе,
а REST и WebSocket проксируются к локальному gateway через порт `5173`. Поэтому
для телефона не требуется отдельно публиковать порт gateway. Прямой доступ к
gateway на `3001` оставлен для production и настраивается отдельно.

Состояние связи доступно по `http://127.0.0.1:3001/api/health`.

Мобильный доступ открывается по `/mobile`: после входа доступны редактор точек и
ограниченный пульт непрерывного/шагового JOG. На основном HMI должна быть активна
сессия того же пользователя. Полная инструкция для разработки и production:
[запуск и мобильный доступ](../DOKS/04-run-and-ip.md#мобильный-доступ-редактор-точек-и-jog-пульт).

```powershell
npm run build
node --check gateway/server.mjs
```

Каталоги `node_modules`, `dist`, `storybook-static` и `artifacts` генерируются локально и не должны попадать в Git.
