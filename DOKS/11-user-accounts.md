# Учётные записи HMI

Пользователи и серверные сессии принадлежат OPC UA gateway. PLC не хранит
логины, пароли и роли. Хранилище по умолчанию:
`visu/gateway/data/auth.sqlite`.

При первом запуске пустой базы gateway создаёт администратора `admin` с временным
паролем `admin`. После входа пароль нужно заменить через панель пользователей.
Начальные значения можно переопределить переменными
`AUTH_BOOTSTRAP_ADMIN_USERNAME` и `AUTH_BOOTSTRAP_ADMIN_PASSWORD`.

Пароли сохраняются только в виде `scrypt`-хеша с отдельной случайной солью.
Сессия передаётся cookie `portal_session` с атрибутами `HttpOnly`, `SameSite=Strict`
и временем жизни 12 часов. Время жизни меняется через `AUTH_SESSION_HOURS`.

## API

- `GET /api/auth/session` — текущая сессия;
- `POST /api/auth/login` — вход;
- `POST /api/auth/logout` — выход;
- `GET /api/users` — список пользователей, только администратор;
- `POST /api/users` — создание пользователя, только администратор;
- `PUT /api/users/:id` — редактирование, блокировка и смена пароля;
- `DELETE /api/users/:id` — удаление пользователя.

Без сессии обычный WebSocket `/ws` работает только в гостевом режиме: публикует
состояния ячейки и циклограмму, но отклоняет управляющие команды. События аудита,
тестовые прогоны и другие закрытые сообщения гостю не транслируются. Тестовый runner
использует отдельный одноразовый токен и не зависит от пользовательской cookie.
Нельзя удалить собственную запись или удалить, отключить либо понизить последнего
активного администратора.

Команды HMI, входы/выходы и изменения учётных записей записываются в журнал работы
ячейки с `actor_user_id`, логином и отображаемым именем инициатора. Фильтр журнала
по аккаунту доступен любой действующей сессии через `GET /api/cell-event-actors`;
список включает и пользователей, для которых сохранилась историческая запись.

Текущий этап различает роли `admin` и `operator`. Детальная матрица разрешений на
PLC-команды добавляется следующим этапом; технологические проверки и безопасность
в любом случае остаются в PLC.
