# Журнал работы ячейки

Журнал формирует OPC UA gateway на промышленном компьютере. PLC не хранит историю.
SQLite-файл: `visu/gateway/data/cell-events.sqlite`. Срок хранения по умолчанию —
90 дней, переменная окружения `CELL_EVENTS_RETENTION_DAYS`.

## Принадлежность событий

| ID | Источник |
| --- | --- |
| 1–3 | Станки 1–3 |
| 4 | Магазин |
| 5 | Робот |
| 6 | Оператор |
| 7 | Аварии и предупреждения |
| 8 | Система, OPC UA и Modbus-связь |

Запись содержит время, источник, тип и статус события, текст, код, `operation_id`,
`CommandSeq`, `requestId`, старое/новое значения, дополнительные параметры и
аккаунт-инициатор (`actor_user_id`, логин и отображаемое имя). Для событий
оборудования и связи аккаунт отсутствует; команды HMI и аудит учётных записей
сохраняются с пользователем, который их выполнил.
Полный снимок регистров сохраняется только при смысловом переходе Modbus-команды.

Экран «Журнал событий» показывает историю в реальном времени и фильтрует её по
принадлежности, аккаунту, произвольному диапазону дат и времени, проблемным
статусам, категории, порядку и тексту. `GET /api/cell-event-actors` возвращает
доступные для фильтра аккаунты, а `GET /api/cell-events` принимает
`actorUserId`, `from` и `to` в миллисекундах Unix.
