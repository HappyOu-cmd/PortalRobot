# Python-симулятор робота SC-500

## Назначение

`robot_simulator` имитирует программу внешнего контроллера робота и Modbus TCP
Server для проверки PLC-клиента. Он использует протокол v3 и карту
[`1001–1117`](08-sc500-modbus-register-map.md): FC16 записывает полный блок
`1001–1009`, где `1005 = ActiveSlot`, `1006 = MagazineId`; FC03 читает
`1101–1117`, PDU-адреса начинаются с `1000` и `1100`.

## Запуск

```powershell
cd "C:\Users\KOKSHAROV IR\Desktop\Project\Portal robot\robot_simulator"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\run_simulator.bat
```

По умолчанию сервер слушает `0.0.0.0:502`, Unit ID `1`. Для PLC указывается IP
компьютера с симулятором. Параметры сервера, точки, отдельная геометрия двух магазинов, динамика и времена
захватов редактируются в интерфейсе и сохраняются в `config.json`.

Тот же процесс публикует локальный test-control API `127.0.0.1:8765`. Он нужен
только автоматическому runner и недоступен с других компьютеров. Runner не
создаёт второй симулятор: он временно получает эксклюзивную сессию у уже
открытого окна, задаёт `Automatic`, FAST/Realtime и тестовые аварии. При потере
runner сессия освобождается по watchdog.

## Модель контроллера

- `Автоматический`: Auto/Remote/Drives/Homed/Ready, команды PLC разрешены.
- `Ручной`: локальный пульт разрешён, команды PLC получают `ResultCode 4`.
- `Остановлен`: Drives и Ready сняты, команды PLC получают `ResultCode 4`.
- Без аварий статусные слова равны `0x019F` в Auto, `0x0119` в Manual и
  `0x0111` в Stopped.
- Команда защёлкивается по новому ненулевому `CommandSeq`; `AckSeq` при аварии
  не очищается. Повтор выполняется только новым sequence.
- S-профиль использует скорость, ускорение, замедление и jerk; координаты
  обновляются во время `BUSY` и публикуются как signed DINT × 0,1 мм.
- Stop движения тормозит, Stop захвата/переворота ждёт окончания действия.
- Аварийные причины снимаются отдельной кнопкой, но защёлка очищается только
  Reset. Потеря heartbeat PLC останавливает действие и снимает Ready.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest
```

Набор проверяет модель автомата и реальный TCP round-trip FC16/FC03. Для запуска
без интерфейса применяется `run_simulator.bat --headless`; тестовый порт можно
передать через `--port`, порт управляющего API — через `--control-port`.
